# 🤖 Automação RPA - Fornecedores (Flowchart)

Este projeto implementa uma automação inteligente para *cadastro e controle de fornecedores, utilizando **Python* e *BotCity, com interface gráfica via **Tkinter* e integração com *planilhas Excel*.  
O objetivo é reduzir tarefas manuais repetitivas e otimizar o fluxo operacional do setor de suprimentos.

---

## 🧠 Visão Geral

A automação foi projetada para:

- Ler e processar uma planilha de fornecedores;
- Extrair, validar e manipular dados automaticamente;
- Executar tarefas de preenchimento e atualização em sistemas internos;
- Exibir logs e mensagens via interface gráfica (Tkinter);
- Registrar cada etapa do processo de forma visual e auditável.

---

## ⚙ Tecnologias Utilizadas

| Tecnologia | Função |
|-------------|--------|
| 🐍 *Python 3* | Linguagem principal do projeto |
| 🧩 *BotCity* | Framework RPA utilizado para controlar interface e automações |
| 📊 *Excel / openpyxl* | Leitura e manipulação de dados |
| 🪟 *Tkinter* | Criação de interface gráfica com botões e logs |
| 🦊 *Geckodriver (Firefox)* | Automação de navegador via Selenium |
| 💻 *Batch / PowerShell / Shell* | Scripts auxiliares de execução |
| 🔐 *.env* | Armazenamento de variáveis sensíveis |
